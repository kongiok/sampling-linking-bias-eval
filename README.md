# sampling-linking-bias-eval

## Purpose

The core inspiration for this project stems from Chapter 4 of *Producing Citizenship in Medical Research Collections* (Million Death Study): "**A dataset is inherently incomplete. How can we, from a data science perspective, minimize real-world imperfections?**"[cite: 1] Through manual error injection and data simulation, this project aims to explore and quantify the impact of sampling quality and linking bias on machine learning models and statistical inference[cite: 1].

## Architecture

The project architecture is divided into two main components:

1. **Presentation**
   - Covers midterm and final presentations (To be continued).
   - Built using the **[Slidev](https://sli.dev/)** presentation framework.

2. **Data Analysis**
   - Utilizes **Jupyter Lab** paired with **Python** for data processing, bias simulation, and model evaluation.
   - Per course requirements, all analytical workflows and experimental results are formatted and delivered as `.ipynb` notebooks[cite: 3].
